# 🌤️ Android Task 05: Live Weather Forecast App

Official Android Application built for the **Prodigy InfoTech Android Application Development Track**.

## 🌟 Key Features
- **Retrofit REST API Integration**: Async HTTP networking via Kotlin Coroutines.
- **City Weather Search**: Live temperature, weather condition, and icon updates.
- **5-Day Forecast**: Multi-day metric forecasts.
