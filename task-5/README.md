### 📌 Description
Real-time weather query dashboard fetching OpenWeatherMap API metrics (temperature, humidity %, wind speed, pressure, UV index) with mock fallback engine and 5-day forecast cards.

### 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- Async Fetch API / JavaScript (ES6)
