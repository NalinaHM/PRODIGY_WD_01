## 🛠️ Summary & Tech Stack
- **Language**: Kotlin 1.9+
- **Architecture**: MVVM with Jetpack ViewModel & LiveData
- **UI Framework**: Material Design 3 (XML Layouts & ViewBinding)
- **Local Persistence**: Room Database
- **Networking**: Retrofit 2 & OkHttp
