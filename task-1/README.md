### 📌 Task Overview
This repository contains the complete implementation for **Task 01** of the Prodigy InfoTech Web Development Internship Track.

### ✨ Key Features Implemented
1. **Fixed Position Navigation Header**: Pins to the top of the viewport continuously.
2. **Dynamic Scroll Transitions**: Transforms background opacity, backdrop blur (`backdrop-filter`), padding, and border glow upon scrolling past 50px.
3. **Hover & Active Section Tracking**: Dynamic link hover state animations and auto-highlighting of navbar links based on current visible section.
4. **Interactive Theme Customizer Studio**: Live palette switcher (Cyber Indigo, Electric Cyan, Mint Emerald, Sunset Crimson) updating CSS variables across the navbar in real time.
5. **Scroll Status Monitor Bar**: Displays real-time scroll pixel offsets, navbar state, and active section target.
6. **Responsive Hamburger Drawer Menu**: Smooth navigation drawer for mobile viewports.
7. **FAQ Accordion & Form Validation**: Expandable FAQ items and contact form input validation.

### 🛠️ Tech Stack
- HTML5
- CSS3 (Custom properties, Glassmorphism, CSS Grid)
- Vanilla JavaScript (ES6)
