# Prodigy InfoTech Data Science Track - Task 01
## Demographic Distribution Analysis & Visualization

### 📌 Overview
Create a histogram and bar charts to visualize the distribution of continuous (Age, Income) and categorical (Gender, Education, Country) variables in a population dataset.

### 🛠️ Workflow & Analysis
1. **Dataset Generation**: `generate_data.py` constructs a 1,500-person demographic sample with realistic log-normal income and triangular age distributions.
2. **Distribution Analysis**: `analyze_visualize.py` performs frequency analysis:
   - **Continuous Variable (Histogram Binned)**: Age groups (`18-24`, `25-34`, `35-44`, `45-54`, `55-64`, `65+`).
   - **Categorical Variables (Bar Chart Counts)**: Gender composition, Education breakdown, and Country frequencies.

### 🚀 How to Run

```bash
# Run Demographic Analysis
python analyze_visualize.py
```
