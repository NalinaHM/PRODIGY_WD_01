# Prodigy InfoTech Internship - Task 02
## Stopwatch Web Application

### Description
A web-based stopwatch featuring Start, Pause, Resume, Reset, and Lap recording with fastest/slowest lap highlighting.

### Technologies Used
- HTML5
- CSS3 (Flexbox, CSS Variables, Centisecond Typography)
- Vanilla JavaScript (ES6)

### How to Run
Open `index.html` in any web browser.
