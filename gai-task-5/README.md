# 👁️ GenAI Task 05: Multimodal AI Vision & Audio Synthesizer

Official Generative AI application built for the **Prodigy InfoTech Generative AI Track**.

## 🌟 Key Features
- **Visual Scene Captioning**: Vision Transformer (ViT) image feature extraction.
- **Multimodal Visual Q&A**: Question answering over uploaded image scenes.
- **Text-to-Speech (TTS) Synthesis**: Neural audio waveform rendering.

## 📁 Files Included
- [`index.html`](index.html) - Interactive Web-Based Multimodal Studio.
- [`multimodal_ai.py`](multimodal_ai.py) - Python multimodal vision & audio synthesis script.
