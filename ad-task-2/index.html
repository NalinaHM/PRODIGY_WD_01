Task Manager & To-Do App

An Android Task Manager application featuring task CRUD, priority tags, checkmark completion, and Room DB local persistence.

Room DB

⚙️ Room DB & RecyclerView Controller

Uses Android Jetpack Room Persistence Library with ViewModel and LiveData to maintain local task state across app restarts.

📄 TaskEntity.kt & MainActivity.kt Snippet

@Entity(tableName = "tasks")
data class TaskEntity(
    @PrimaryKey(autoGenerate = true) val id: Int = 0,
    val title: String,
    val priority: String = "HIGH",
    var isCompleted: Boolean = false
)

class MainActivity : AppCompatActivity() {
    private val taskViewModel: TaskViewModel by viewModels()

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        val adapter = TaskAdapter { task -> taskViewModel.toggleTask(task) }
        binding.recyclerView.adapter = adapter

        taskViewModel.allTasks.observe(this) { tasks ->
            adapter.submitList(tasks)
        }
    }
}
