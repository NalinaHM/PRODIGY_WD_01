## 🛠️ Project Descriptions & Tech Stack

### 1. 🌐 Task 01: Responsive Landing Page & Navigation Menu
- **Description**: Fixed-position navigation header with dynamic scroll styling (glassmorphism backdrop blur, opacity, padding shift), hover states, active section tracking, Theme Studio switcher, and responsive mobile navigation drawer.
- **Tech**: HTML5, CSS3, ES6 JavaScript.

### 2. ⏱️ Task 02: Stopwatch Web Application
- **Description**: Centisecond timer (`00:00:00.00`) featuring Start, Pause, Resume, Reset, and Lap History logging with auto-highlighting for best/worst laps.
- **Tech**: HTML5, CSS3, ES6 JavaScript.

### 3. 🎮 Task 03: Tic-Tac-Toe Web Application
- **Description**: Interactive grid game supporting 2 Players (PVP) mode and an unbeatable Minimax AI engine, scorekeeping, and winning line animations.
- **Tech**: HTML5, CSS3, ES6 JavaScript (Minimax Algorithm).

### 4. 👨‍💻 Task 04: Personal Developer Portfolio Website
- **Description**: Responsive portfolio featuring skill proficiency bars, filterable project showcase cards, developer bio, resume downloader, and contact form validation.
- **Tech**: HTML5, CSS3, ES6 JavaScript.

### 5. 🌤️ Task 05: Live Weather Application
- **Description**: Real-time weather query dashboard fetching OpenWeatherMap API metrics (temperature, humidity %, wind speed, pressure, UV index) with mock fallback engine and 5-day forecast cards.
- **Tech**: HTML5, CSS3, Async Fetch API / JavaScript.
