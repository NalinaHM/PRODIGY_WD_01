## ⚙️ Installation & How to Run

### 1. Web Applications & Interactive Hubs
Simply open any of the HTML files in a browser:
- Master Web Suite: `index.html`
- Machine Learning Suite: `ml_dashboard.html`
- Data Science Suite: `ds_dashboard.html`
- Android Application Suite: `ad_dashboard.html`
- Generative AI Suite: `gai_dashboard.html`
- Software Development Suite: `sd_dashboard.html`
- Full Stack Web Suite: `fs_dashboard.html`
- Backend Web Suite: `be_dashboard.html`
- Software Testing Suite: `st_dashboard.html`

Alternatively, start a local HTTP server:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

---

### 2. Machine Learning & Data Science Python Scripts
Run ML or DS pipeline verification scripts:
```bash
python run_all_ml_tasks.py
python run_all_ds_tasks.py
```

---

### 3. C++ / Python / Node.js Backend Executables
- C++ Temperature Converter:
  ```bash
  g++ -o converter sd-task-1/converter.cpp
  ./converter
  ```
- Python Scripts (Sudoku Solver, Web Scraper, Rate Limiter, etc.):
  ```bash
  python sd-task-4/sudoku_solver.py
  python sd-task-5/web_scraper.py
  python be-task-3/rate_limiter.py
  python st-task-1/test_suite.py
  ```
- Node.js Services:
  ```bash
  node fs-task-1/server.js
  ```
