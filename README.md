## 🛠️ Detailed Project Descriptions

### 🌐 Web Development Projects
1. **Task 01 - Landing Page & Navigation Menu**: Fixed-position navbar, glassmorphism scroll transitions, hover state animations, real-time scroll position monitor, and theme color customizer studio.
2. **Task 02 - Stopwatch App**: Centisecond timer (`00:00:00.00`) with start/pause/reset controls, lap recording, and best/worst lap highlighting.
3. **Task 03 - Tic-Tac-Toe Game**: 2 Players (PVP) mode, unbeatable **Minimax AI** decision algorithm, scorekeeping, and winning line animations.
4. **Task 04 - Developer Portfolio**: Interactive skill progress bars, category filterable project gallery (`All`, `Web Apps`, `UI`), bio, and contact form validation.
5. **Task 05 - Weather Dashboard**: Real-time OpenWeatherMap API query dashboard with humidity, wind speed, pressure, UV index, mock fallback, and 5-day forecast.

### 🤖 Machine Learning Projects
1. **ML Task 01 - House Price Prediction**: Linear Regression model predicting home prices based on square feet, bedrooms, bathrooms, house age, and garage capacity.
2. **ML Task 02 - Customer Segmentation**: K-Means clustering algorithm identifying retail customer personas based on Annual Income & Spending Score.
3. **ML Task 03 - Dog vs Cat Image Classifier**: SVM RBF-kernel classifier distinguishing image feature vectors of cats 🐱 vs dogs 🐶.
4. **ML Task 04 - Hand Gesture Recognition**: Random Forest multi-class gesture model classifying 5 hand gestures (Open Palm 🖐️, Closed Fist ✊, Peace Sign ✌️, Thumbs Up 👍, OK Sign 👌) for HCI control.
5. **ML Task 05 - Food Recognition & Calorie Estimator**: Multi-output classifier and Gradient Boosting regressor identifying food items (Pizza, Salad, Burger, Sushi, etc.) and estimating calorie content per 100g.
