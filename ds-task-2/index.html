💡 Data Cleaning & Key EDA Insights
1. Missing Value Imputation: Age missing values imputed using median grouped by Pclass and Sex.
2. "Women & Children First": Female passengers achieved a 79.81% survival rate compared to 19.69% for male passengers.
3. Socio-Economic Status Bias: 1st Class passengers had a 56.0% overall survival rate vs 31.98% for 2nd Class and 37.74% for 3rd Class.
