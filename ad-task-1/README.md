# 📱 Android Task 01: Unit & Currency Converter App

Official Android Application built for the **Prodigy InfoTech Android Application Development Track**.

## 🌟 Key Features
- **Multi-Category Conversion**: Length, Weight, Temperature, and Currency.
- **Real-Time Input Calculation**: Instant result updating via Kotlin `TextWatcher`.
- **Material 3 UI**: Sleek dark mode aesthetics with responsive smartphone layout.

## 📁 Files Included
- [`index.html`](index.html) - Interactive Web-Based Android Application Simulator.
- [`MainActivity.kt`](MainActivity.kt) - Kotlin Activity controller logic.
